# NewGameStudio website

One static page for the studio: TypeScript, React 19, Vite. `README.md` is the short guide and
holds the server and deploy setup ("Deploy and server"); `SITE-GUIDE.md` explains every section of
the page and where it lives.

## Commands

- `npm ci` once, then `npm run dev` for the dev server.
- Verify with `npm run build`: it typechecks, then bundles into `dist/`. There are no tests and no
  linter.
- A change to `deploy/Caddyfile`: `docker run --rm -v "$PWD/deploy/Caddyfile:/etc/caddy/Caddyfile:ro" caddy:2 caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile`.

## Rules

- A push to `main` goes live (`.github/workflows/deploy.yml`). Work on a branch and open a pull
  request; never push `main` unless asked.
- The repository is public: never commit a key, a password or the server's address.
- Images under `public/assets/` keep their real `width`/`height` in `src/data/site.ts`. The Gallery
  title SVG and the moment frames are generated by `tools/`; re-run the tool, never hand-edit them.
- A change to what the page does or where code lives updates `SITE-GUIDE.md` in the same change.
- Commit messages never credit an AI: no `Co-Authored-By` naming a model, no `Generated with`.
